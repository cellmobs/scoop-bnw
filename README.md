# Scoop bucket for BNW

[BNW](https://github.com/cellmobs/bnw-releases) is a local-first peer-to-peer network for people, agents, and AI capabilities.

```powershell
scoop bucket add bnw https://github.com/cellmobs/scoop-bnw
scoop install bnw/bnw
bnw setup
```

The manifest in `bucket/` is updated by the BNW release workflow for each release; do not edit it by hand.
